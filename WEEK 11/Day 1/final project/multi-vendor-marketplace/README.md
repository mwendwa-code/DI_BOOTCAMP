# Multi-vendor Marketplace

Starter scaffold for a multi-vendor marketplace built with Express and EJS.

## Getting started

1. Install Node.js.
2. Copy `.env.example` to `.env` if you need to customize the port.
3. Run `npm install`.
4. Run `npm run dev` for development or `npm start` to start the server.
5. Open `http://localhost:3000`.

The routes, controllers, middleware, and database files are placeholders for
future implementation. No database or payment provider has been selected yet.
